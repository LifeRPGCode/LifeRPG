# LifeRPGCode

**Life is an RPG. Every decision is a function. Every habit is a loop. Every challenge is a condition.**

I've always liked the idea that life works a bit like code.

Every day the world gives us input.
Our mind processes it through logic, emotions, and experience.
The output is what we choose to do.

```text
Input   → experiences, people, opportunities
Process → thoughts, habits, decisions
Output  → actions, results, growth
```

This repository is my save file.

I'm starting from scratch, learning Python and, later, cybersecurity. Every project here is another quest completed, another skill unlocked, another level gained.

I'm not trying to become a developer overnight. I'm here to learn, build real projects, make mistakes, fix them, and keep moving forward.

No diploma.
No shortcuts.
Just curiosity, consistency, and one commit at a time.

Welcome to my journey.

Welcome to **LifeRPGCode**.
